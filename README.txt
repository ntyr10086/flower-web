🎯 立即開始
═════════════════════════════════════════════════════════════════════════

方式 1：本地測試（開發用）
  $ cd flower-language
  $ python3 -m http.server 8000
  訪問：http://localhost:8000

方式 2：部署到 Vercel（生產用）
  $ npm i -g vercel
  $ cd flower-language
  $ vercel

方式 3：Git + Vercel（自動化）
  • 推送至 GitHub
  • 在 Vercel 連接倉庫
  • 自動部署（每次 push）
